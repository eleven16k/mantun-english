# 悦读馆内容人工审核清单

> 依据 PRD §6.3：所有 AI 生成内容需人工审核后方可上线。每学段内容包生成后，
> 由任课老师按本清单抽审（首批建议全量审，后续每批抽审 ≥30%）。
> 审核位置：`mt-teach-app/content/reading/stories/{track}/*.json`（或对应 data-*.ts）。
> 审核通过的故事文件名在文末登记表登记；发现问题的直接改 json 后重跑 `--assemble` 与音频脚本。

## A. 教学正确性（每篇必审项）

- [ ] **事实/答案正确**：每道题的答案都能从课文直接推出，无歧义、无争议
- [ ] **fill_blank 唯一性**：挖空处填其他选项在语法/语义上确实不成立
- [ ] **sentence_order 原句**：排序句确为课文原句，词序唯一合理
- [ ] **词汇难度**：超纲词（validate 脚本 warnings 列出的 `_unknownWords`）是否需要保留——保留需是可猜测的上下文词，否则替换
- [ ] **语法重点匹配**：课文体现所在区的语法重点（如 r4 区出现 if 条件句）

## B. 语言质量（抽审项）

- [ ] 英语地道自然，无中式英语、无机翻腔
- [ ] 中文翻译准确通顺，符合对应年龄段理解力
- [ ] 句长与蓝图区间一致（validate 脚本会报，重点看异常篇）
- [ ] 无拼写/标点错误；word_builder 词为课文实义词

## C. 内容安全（每篇必审项，红线一票否决）

- [ ] 无暴力、恐怖、血腥描写（含动物受伤等低龄敏感画面）
- [ ] 无早恋/恋爱内容、无性暗示
- [ ] 无宗教、政治敏感、意识形态内容
- [ ] 无刻板印象（性别、地域、种族、家庭形态）；职业与角色多样化
- [ ] 无品牌名、真实人名（名人/学生名）、联系方式
- [ ] 无危险行为模仿引导（如独自游泳、玩火等无警示描写）
- [ ] 价值观正向：故事传递勇气、友善、好奇、坚持等

## D. 音频复核（首批抽听 ≥10%）

- [ ] 听录音：发音清晰、语速合适、无吞字/错读专有名词
- [ ] translation 与音频段落一一对应
- [ ] `-slow` 慢速版可正常播放

## E. 处理流程

1. 发现问题 → 直接修改 `stories/{track}/{id}.json`
2. 重跑：`node scripts/reading/generate-content.mjs --assemble`
3. 若改了课文段落 → 重跑 `python3 scripts/reading/gen_story_audio.py`（增量，只补缺失/改动的段落——改动过的请先删旧 mp3）
4. 重跑 `node scripts/reading/validate-content.mjs` 确认全绿
